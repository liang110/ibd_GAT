# 2025-2026 IBD microbiome transferability search record

Search date: 2026-08-19. PubMed E-utilities were queried after the research-lookup API was unavailable in the workspace. The narrow query combined inflammatory bowel disease, microbiome/metagenome, machine learning or external validation/transferability/confounding, and publication dates 2025-2026.

## Directly relevant peer-reviewed record

Luo Y, Yang Y. Network and machine learning integration reveals gut microbiome biomarkers in pediatric IBD. **BMC Microbiology**. 2025;25:797. DOI: [10.1186/s12866-025-04602-3](https://doi.org/10.1186/s12866-025-04602-3). PubMed PMID: 41430556.

The study is an application-oriented pediatric IBD biomarker analysis using network and machine-learning integration. It is relevant as a contemporary comparator showing that IBD microbiome ML remains dominated by biomarker-discovery objectives. It does not provide the same three-cohort, six-direction, fixed-contract, source-only external-transfer estimand, so it should not be used to claim that transferability has already been established or solved.

## Search boundary and interpretation

The search did not identify a peer-reviewed 2025-2026 IBD microbiome paper that reproduces the full combination of fixed species contract, reciprocal multi-cohort transfer, source-only nested preprocessing, participant-cluster uncertainty and explicit confounding/leakage audit. This is a scope observation, not evidence of priority or novelty. The manuscript uses the records above to calibrate claim strength: recent external-validation studies motivate the benchmark, cross-population and geography papers limit biological generalization, and population-structure/multivariable methods clarify what the present taxonomic benchmark does not control. The 2026 preprint noted in the project guidance is excluded from the manuscript because it is not peer reviewed.
