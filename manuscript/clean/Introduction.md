# Introduction

Inflammatory bowel disease (IBD) is a heterogeneous group of chronic intestinal disorders in which microbial community structure, microbial activity and host inflammation interact. Cohort studies have identified reproducible changes in taxa, pathways and metabolites, while also showing that the magnitude and direction of these changes vary with disease phenotype, treatment, geography and sampling design [1–9]. A microbiome classifier can therefore achieve a high internal score by using measurement scale, repeated observations, cohort origin or metadata shortcuts rather than a signal that transfers to a new study. External validation is consequently a measurement problem as well as a modelling problem.

Microbiome machine-learning workflows have established the value of study-aware splitting, compositional analysis and explicit confound control [10–12]. The information boundary is particularly important for a longitudinal source cohort and an independent cross-sectional target: repeated visits can make the effective sample size appear larger, whereas a pooled target can hide origin-specific performance. A valid comparison must state which features are shared before modelling, which transformations are fitted on source participants, which target quantities are withheld and which unit is resampled for uncertainty.

The representation introduces a second boundary. Microbiome measurements are compositional, so closure, zero handling and scale harmonization affect the geometry available to a classifier [13–22]. Feature profiling tools define the taxonomic inputs used by these models [23–26], while penalized regression, random forests and boosting provide strong marginal references [27–30]. Graph attention networks instead propagate feature information over a declared topology [31–36]. This can be useful when associations transport across domains, but the topology can also encode source-specific covariance. The relevant question is therefore not whether a graph network is generally superior to a tabular model. It is whether, under a frozen feature contract and a declared source-to-target direction, the relational representation adds measurable information beyond strong marginal references.

We develop a framework for that question as a sequence of auditable estimands. The framework (i) fixes a label-free microbial registry and common metadata boundary; (ii) fits closure, CLR, scaling, prevalence filtering, feature selection and graph construction only on source-training participants; (iii) evaluates both directions with participant-grouped splits and participant-cluster bootstrap; and (iv) separates method validation from transfer using known-truth controls, origin-held-out tests, topology nulls and an approximate no-message comparator. The graph branch is consequently one representation under test, not the definition of the framework.

We apply the framework to HMP2/IBDMDB and PRISM for the binary IBD-versus-non-IBD endpoint. The shared registry contains 126 microbial features and no exact-name shared metabolites. We report the provenance and exclusion contract, leakage and known-truth controls, PRISM origin transfer, ten-repeat bidirectional transfer, topology diagnostics and capacity comparison. The resulting claim is deliberately bounded: the framework identifies a conditional forward relational gain in one cohort direction and shows where that gain disappears.
